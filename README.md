# 源色度 CHROMA · YUAN

**先理解参考风格，再适配每一张原图。**

源色度 CHROMA 是摄影调色技能。Agent分析参考照片的影调、反差、冷暖、色系和质感，确定性像素引擎处理原图，交付原分辨率PNG、前后对比、处理计划和质量报告。

## 两个版本

| 版本 | 技能标识 | 区别 |
| --- | --- | --- |
| 普通版 | `yuan-chroma-photo-colorist` | 参考风格分析、逐图适配、像素调色与基础质量报告 |
| Plus版 | `yuan-chroma-photo-colorist-plus` | 增加风格参数校准、真实成片变化审计和偏轻时的定向修订流程 |

两个版本使用相同的像素渲染器。Plus增强的是参数校准和结果复查，不是简单把饱和度或强度拉高。

## 功能与边界

- 支持参考风格迁移、预设/强度控制和成组照片逐张处理。
- 可分析新参考，不限于随包三套数值案例；数值实例不能按名字硬套新照片。
- 同坐标修改颜色和明暗，不重绘、不裁切、不改脸、不造物；允许RGB值改变，不承诺像素值完全不变。
- 不保证还原作者原始参数、LUT或参考中的物理日照；不生成新太阳与阴影。
- 云端执行路线优先普通SDR JPG/PNG，HEIC先导出SDR/sRGB副本；输出8位SDR PNG，不声称RAW/HDR重建。
- 肤色/天空约束包含宿主看图判断和颜色族限幅，不是完整自动语义分割。
